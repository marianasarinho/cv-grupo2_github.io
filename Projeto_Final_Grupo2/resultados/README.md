# Resultados selecionados

Esta pasta contém uma seleção das evidências obtidas em 02/08/2026.

- `testes_finais/`: telas completas com acertos, erros e confiança;
- `mapas_disparidade/`: exemplos de profundidade para diferentes materiais;
- `csv_sessoes/`: métricas automáticas da sessão final de testes;
- `validacao_retificacao/`: verificação visual das linhas epipolares.

As capturas repetidas das câmeras esquerda e direita foram retiradas desta versão para reduzir o tamanho do repositório. Os resultados completos permanecem no backup original do grupo.
